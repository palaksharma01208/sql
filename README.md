# Online Store - SQL Project

Analyzed an online store database to uncover key business insights.

### Tables Used:
Customers, Products, Orders, Order Items, Employees

### Key Insights I Found:
- Identified the highest revenue-generating city and top 3 customers by total spending, excluding cancelled orders
- Determined the peak sales month to understand seasonal demand
- Flagged low-stock products that were frequently ordered for timely restocking
- Compared employee salaries against their department averages to highlight high performers

### SQL Skills Used:
DDL, DML, DQL, DCL, TCL, Joins (Inner, Left, Right), GROUP BY, Subqueries, CASE, Views, CTEs (WITH), Window Functions (RANK, ROW_NUMBER), Transactions, SAVEPOINT, GRANT / REVOKE
